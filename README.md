# HD Trade — уебсайт

Статичен уебсайт на HD Trade (Ейч Ди Трейд ЕООД, Габрово) — климатизация, вентилация и термопомпи.

## Структура

- `*.html` — страниците на сайта (генерирани, не се редактират ръчно)
- `assets/css/style.css` — дизайн токени и компоненти
- `assets/js/main.js` — меню, слайдер, форма, позициониране на въздушния поток
- `assets/img/` — лого, иконка и снимки
- `_build/build.py` — генератор: общ хедър/футър, съдържание на страниците, SVG анимацията

## Промяна на съдържанието

Редактирайте текстовете в `_build/build.py`, след това:

```bash
python3 _build/build.py
```

## Преди пускане

- Формата за оферта няма сървър — сега отваря имейл клиента на посетителя.
- Проектите на страница „Проекти“ са примерни и трябва да се заменят с реални.
