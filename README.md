# HD Trade — уебсайт

Статичен уебсайт на HD Trade (Ейч Ди Трейд ЕООД, Габрово) — климатизация, вентилация и термопомпи.

## Структура

- `*.html` — страниците на сайта (генерирани, не се редактират ръчно)
- `assets/css/style.css` — дизайн токени и компоненти
- `assets/js/main.js` — меню, слайдер, форма, позициониране на въздушния поток
- `assets/js/calc.js` — изчисленията на калкулатора (без DOM, тества се с Node)
- `assets/js/calculator.js` — интерфейсът на калкулатора (стъпки и резултат)
- `tests/calc.test.js` — тестове на изчисленията
- `assets/img/` — лого, иконка и снимки
- `_build/build.py` — генератор: общ хедър/футър, съдържание на страниците, SVG анимацията

## Промяна на съдържанието

Редактирайте текстовете в `_build/build.py`, след това:

```bash
python3 _build/build.py
```

## Калкулатор за мощност

Страница `kalkulator.html`. Четири модула: климатик (една или няколко стаи), термопомпа въздух-вода,
вентилация (рекуператор) и офис сграда (VRV/VRF). Препоръчва **клас мощност** (напр. „Сплит климатик 3,5 kW“,
„Термопомпа 12 kW“, „Рекуператор 500 m³/ч“), без марки и модели, плюс ориентировъчна цена за монтаж по ценоразписа.

Всички коефициенти, стандартни мощности и цени са в `CONFIG` в началото на `assets/js/calc.js`.
Те са начални стойности по общоприети инженерни правила и трябва да се нагласят по реални изпълнени обекти.
Модулите могат да се отварят директно: `kalkulator.html#split`, `#heatpump`, `#vent`, `#building`.

## Тестове

```bash
npm test
```

Изисква Node.js 18 или по-нов. Тестовете проверяват изчисленията с примери, сметнати на ръка
(сметката е записана до всеки тест). След промяна на коефициент в `CONFIG` обновете и очакваните стойности.

## Преди пускане

- Формата за оферта няма сървър — сега отваря имейл клиента на посетителя.
- Проектите на страница „Проекти“ са примерни и трябва да се заменят с реални.
